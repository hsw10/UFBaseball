# UFBaseball

A standalone University of Florida Baseball news digest, designed for GitHub Pages. The homepage displays the 25 newest relevant stories across all configured sources in one 5×5 grid with thumbnails.

## Sources

- Florida Gators — Baseball
- GatorCountry — Baseball
- Gators Wire
- Alligator Army
- WRUF Sports — Baseball
- Swamp247
- Gators Online
- The Independent Florida Alligator — Sports

Some publishers have native feeds; sources without a usable feed are collected through a topical site-restricted Google News fallback. A source can be present but contribute no card during a quiet period.

This repository is intentionally separate from the existing Yankees briefing site.
